## 1. PBR ってなに?

### ひとことで言うと

**PBR(物理ベースレンダリング)** とは、
「**この物体は何でできているか**」を教えると、**光の当たり方に応じて自動的にそれっぽく見せてくれる**描き方のことです。

### MMD 標準の描き方との違い

MMD 標準の描き方では、「この部分はこの色」「ハイライトはこの位置にこのくらい」というように、
**見た目そのもの**を色で指定していました。そのため、照明を変えると不自然になりがちです。

PBR では、見た目そのものではなく、**物体の性質**を指定します。

| MMD 標準の考え方 | PBR の考え方 |
|---|---|
| 「ここは明るい灰色で、白いハイライトを付ける」 | 「これは**ツルツルに磨いた金属**」 |
| 「影の部分は青っぽい色にする」 | (指定しない。周りの空の色から自動で決まる) |

性質を指定しておけば、夕焼けの中でも、暗い室内でも、スポットライトの下でも、
**その場の光に合った見た目**に自動で変わります。これが PBR の一番のメリットです。

### 現実の物の見え方は「2 種類の光」でできている

PBR を理解するコツは、物の見た目が次の 2 つの光の足し算でできている、と知ることです。

```
  ① 表面でそのまま跳ね返る光 (映り込み・ツヤ)      … 「鏡」のような成分
  ② 中に少し入り込んで、色が付いて出てくる光(地の色) … 「絵の具」のような成分
```

- **① 映り込み(ツヤ)**: 窓ガラスに景色が映る、車のボディに空が映る、ビー玉のキラッとした光。
  これは物の色に関係なく、**光の色のまま**跳ね返ります。
- **② 地の色**: 赤いリンゴが赤く見える理由。光が表面のごく浅いところに入り込み、赤以外の色が吸収されて出てくる光です。

Subayai の材質設定は、だいたい「**①と②をどのくらいの割合で、どんな風に出すか**」を決めるものだと思ってください。

## 2. まず覚えるのは 3 つだけ

最初はこの 3 つだけ覚えれば、ほとんどの物はそれらしく見せられます。

### (1) `Category` … 「何でできているか」の大分類

| 書き方 | 意味 | 例 |
|---|---|---|
| `Category : default` | ふつうの物(①映り込み + ②地の色 の両方を持つ) | 服、プラスチック、木、髪、床 |
| `Category : metal` | 金属(①映り込みだけ。映り込み自体に色が付く) | 金、銀、鉄、アクセサリー |
| `Category : glass` | 透明な物(①映り込み + 向こうが透けて見える) | ガラス、氷、宝石、シャボン玉 |
| `Category : sss` | 光が中でにじむ物 | 肌、ろうそく、ゴム、果物 |
| `Category : blackbody` | 光の影響を受けない(自分で光る物向け) | ディスプレイ、ネオン、ランプの光源部分 |

> **金属だけ特別な理由**: 金属は②「地の色」を持たず、**①映り込みそのものに色が付きます**。
> 金の指輪が金色に見えるのは、映り込んだ景色が金色に染まるからです。
> そのため金属は、材質の色が「映り込みの色」として使われます。

### (2) `Roughness` … 表面がどのくらいザラザラか(0 ~ 1)

**映り込みのボケ具合**を決める、一番よく触るパラメータです。

```
 Roughness : 0     ←――――――――――――――→   Roughness : 1
 鏡・磨いた金属・ガラス     サテン・プラスチック     布・紙・マットな壁
 くっきり映り込む          ぼんやり光る            ツヤがほぼ無い
```

- 現実の例えで言うと「**どれだけ磨いたか**」です。磨くほど 0 に近づきます。
- 濡れた路面は 0 に近く、乾いた路面は 1 に近い、というイメージです。
- 省略した場合は `0.5`(ほどよいツヤ)になります。

### (3) `IOR` … 映り込みの強さ(ふつうは 1.3 ~ 1.8)

`IOR`(屈折率)は本来「光がどのくらい曲がるか」を表す物理の値ですが、
Subayai では主に **「正面から見たときに、どのくらい映り込むか」** を決める値として働きます。

| 値 | 正面での映り込みの強さ(目安) | 現実の例 |
|---|---|---|
| `IOR : 1.33,0` | 約 2% | 水 |
| `IOR : 1.5,0` | 約 4% | ガラス、プラスチック、ほとんどの物(**省略時の値**) |
| `IOR : 1.8,0` | 約 8% | ツヤの強いコーティング |
| `IOR : 2.38,0` | 約 17% | ダイヤモンド |

- 迷ったら **書かない**(=1.5)で大丈夫です。
- 2 つ目の数字(`,0` の部分)は「虹色の分かれ方(分散)」用ですが、今のところ使われていないので `0` のままにしてください。
- `Category : metal` の場合、IOR は使われません(映り込みの強さ・色は材質の色で決まります)。

#### ちょっとした豆知識: 斜めから見ると誰でも鏡になる

湖を真上から見ると底が見えるのに、遠く(斜め)を見ると空が映って鏡のように見えますよね。
これは **フレネル効果** と呼ばれる現象で、どんな物でも**斜めから見るほど映り込みが強くなります**。
Subayai はこれを自動で計算するので、IOR は「正面での強さ」だけ決めれば OK です。

## 3. 材質設定ファイルの書き方と使い方

### ファイルの書き方

材質設定ファイルは、ただのテキストファイル(`.txt`)です。メモ帳で作れます。

```text
# ← シャープ(#)から後ろはメモ(コメント)です。自由に書けます

Category : metal        # 金属
Roughness : 0.2         # 少しだけボケた映り込み
```

ルールは次の 4 つだけです。

1. **1 行に 1 つ**、`名前 : 値` の形で書く(`:` の前後の空白はあっても無くても OK)
2. 数字を複数書くときは **カンマ区切り**(例: `IOR : 1.5,0`、`LightVisibility : 1,1,1`)
3. **書かなかったパラメータは自動で標準値**になる(なので必要な行だけ書けば良い)
4. 文字コードは UTF-8 で保存する(日本語のメモを書く場合)

> 何も書かない空のファイル(`default.txt`)は「すべて標準値」= ほどよいツヤのふつうの物、になります。

### MikuMikuDayo での使い方

1. レンダラに Subayai(または Subayai-S)を選ぶ
2. **Materials** ウィンドウを開き、**Subayai** タブを選ぶ
3. 設定したい材質にチェックを入れる(モデル単位でまとめてチェックもできます)
4. **load MatDesc** ボタンを押して、材質設定ファイル(`.txt`)を選ぶ
5. ファイルを書き換えたときは **reload** ボタンで反映できます

便利機能:

- **set recommends**: 材質名に「髪」「肌」「金」「ガラス」「服」「白目」などが含まれていると、
  おすすめの設定ファイルを自動で割り当てます(まだ標準設定のままの材質だけが対象です)。
- **save model's / load model's**: モデル 1 体分の「どの材質にどのファイルを当てたか」を保存・読み込みできます。

### 付属のプリセットを使おう

`renderer/Subayai/m/` フォルダには、すぐ使えるプリセットが入っています。
まずはプリセットを当ててみて、物足りなければコピーして数字を変える、という使い方がおすすめです。

## 5. パラメータ辞典

ここからは必要になったときに引く「辞書」です。全部覚える必要はありません。

### 5.1 基本の性質

| パラメータ | 意味 | 値の目安 |
|---|---|---|
| `Category` | 何でできているか(→ [2章](#1-category--何でできているかの大分類)) | `default` / `metal` / `glass` / `sss` / `blackbody` |
| `Roughness` | 表面のザラザラ具合(→ [2章](#2-roughness--表面がどのくらいザラザラか0--1)) | 0(鏡)~ 1(マット)、標準 0.5 |
| `IOR` | 映り込みの強さ(→ [2章](#3-ior--映り込みの強さふつうは-13--18)) | 1.33 ~ 2.4、標準 1.5 |
| `Anisotropy` | 映り込みのボケを一方向に引き伸ばす | -1 ~ 1、標準 0 |
| `Retroreflection` | 光が来た方向へ跳ね返す割合 | 0 ~ 1、標準 0 |

- **Anisotropy(異方性)**: 髪の毛の「天使の輪」や、鍋底・CD の裏のように**ハイライトが線状に伸びる**見た目を作ります。
  0 なら普通の丸いハイライト、1 や -1 に近づくほど細長くなります(+ と - で伸びる向きが 90° 変わります)。
- **Retroreflection(再帰性反射)**: 道路標識や反射材のように、**ライトを当てた方向にそのまま光を返す**性質です。
  夜の自転車の反射板をイメージしてください。

### 5.2 色の決まり方

物の色(「地の色」= **アルベド** と呼びます)は、基本的に **MMD モデルに設定されている色とテクスチャ** から自動で決まります。

| パラメータ | 意味 |
|---|---|
| `AlbedoEstimation` | MMD 材質のどの色を地の色にするか。`diffuse`(拡散色、**標準**)/ `mmd`(MMD 標準に近い計算、白っぽくなりやすい)/ `ambient`(環境色) |
| `EnableSphereMap` | MMD のスフィアマップを使うか(1 で使う、0 で使わない) |
| `ColorConst` / `ColorConstOp` | モデルを改造せずに色を変える(下の例を参照) |

**色を変える例**(`ColorConst` の 4 つ目の数字は「効き具合」で、0 だと効果なし、1 で完全に適用):

```text
# 色を赤に置き換える
ColorConst : 1,0,0,1
ColorConstOp : default

# 今の色を少し暗くする(明るさを 0.7 倍)
ColorConst : 0,1,0.7,1
ColorConstOp : hsv          # x:色相をずらす / y:鮮やかさの倍率 / z:明るさの倍率
```

> **アルベドについての注意**: アルベドは「照明が当たっていない、物そのものの色」です。
> 影やハイライトを描き込んだテクスチャを使うと、Subayai が計算する影やハイライトと二重になり、不自然になることがあります。

### 5.3 透明度

| パラメータ | 意味 |
|---|---|
| `Alpha` | 不透明度に掛ける倍率。0 で完全に透明、1 でそのまま |
| `Cutout` | 0 で無効。値を入れると、不透明度がその値より低い部分は**完全に透明**、それ以上は**完全に不透明**として描く |

- `Cutout` は葉っぱやレースのような「**切り抜き**」に向いています。半透明の重なりによるチラつきを防げます。
- ガラスのような「透けて見える物」は、Alpha ではなく `Category : glass` を使うと、映り込みと透け感が自然になります。

### 5.4 光る物

| パラメータ | 意味 |
|---|---|
| `Emission` | 光る色と明るさ(R,G,B の 3 つの数字、例 `Emission : 5,5,5`) |
| `Light` | 物の色 × この値 の明るさで光る(例 `Light : 10`) |

- ディスプレイやネオンのような「自分で光る物」には `Category : blackbody` と組み合わせるのがおすすめです(照明の影響を受けず、光る色だけで見た目が決まります)。
- **注意**: Subayai では光る材質は「明るく見える」だけで、**周りを照らしはしません**。周りを照らしたい場合は照明モデル(subalight)を置いてください。

### 5.5 特別な表現

#### 肌・ろうそく(`Category : sss` と `Cat`)

**SSS(表面下散乱)** は、光が物の中に入ってにじんでから出てくる現象です。
懐中電灯を指に当てると指が赤く光る、あの現象です。肌がやわらかく見えるのはこのおかげです。

```text
Category : sss
Cat : 1.0,0.1,0.1,0.03
#     ↑R  ↑G  ↑B  ↑全体の倍率
```

- `Cat` の最初の 3 つは「**赤・緑・青の光がそれぞれどれくらい遠くまでにじむか**」です。
  肌は赤い光が遠くまでにじむので、R だけ大きくします。
- 4 つ目は全体の倍率で、大きくするほど全体がぼやけてやわらかくなります。

#### 車の塗装・濡れた表面(`Clearcoat`)

**クリアコート**は、塗装の上に塗った**透明なニスの層**です。
「下の層の見た目」とは別に、「表面の透明な膜のツヤ」をもう 1 枚重ねられます。

| パラメータ | 意味 |
|---|---|
| `Clearcoat` | 透明な膜の強さ(0 ~ 1) |
| `ClearcoatRoughness` | 膜のザラザラ具合(0 でピカピカ) |
| `ClearcoatIOR` | 膜の映り込みの強さ(IOR と同じ書き方) |

例: マットな布の上に水の膜 → 本体は `Roughness : 1`、膜は `Clearcoat : 1`、`ClearcoatRoughness : 0.1`。

#### アニメ塗り(`Ramp`)

`Ramp` は**陰影の付き方を画像(ランプテクスチャ)で決める**仕組みです。
陰影をパキッと 2 段階にすればトゥーン(アニメ塗り)、肌用の画像を使えばやわらかい陰影になります。
画像とセットで使います(`toon.txt` や `skin.txt` を参照)。

#### 見る角度で色が変わる(`Iridescence`)

玉虫、CD の裏、シャボン玉のように、**見る角度で色が変わる**見た目(構造色)を作ります。
色の変わり方を表す画像(`IridescenceLUT`)とセットで使います(`iridescence.txt`、`shabon.txt` を参照)。

#### 白目(`Sclera`)

`Sclera : 1` を書くと「この材質は白目」という印になり、くぼんだ白目でも自然な向きの陰影になるよう補正されます。

### 5.6 光や影の受け方の調整

現実ではありえない調整ですが、映像作りのために「わざと」光や影を弱めたいときに使います。
どれも R,G,B の 3 つの数字で、`1,1,1` が標準(そのまま)、`0,0,0` で無効です。

| パラメータ | 意味 | 使いどころ |
|---|---|---|
| `LightVisibility` | 照明(太陽・ライト)からの光の受け方 | 顔だけライトを弱める |
| `SkyVisibility` | 空(背景画像)からの光の受け方 | 屋内のシーンで空の影響を減らす |
| `ShadowVisibility` | 影の濃さ | 顔に落ちる影を薄くする(`eye.txt` は 0.3) |
| `AOVisibility` | すき間の暗さ(AO)の強さ | 白目が暗くなりすぎるのを防ぐ |
| `ShadowCaster` | 1 で影を落とす、0 で影を落とさない | 髪の毛の影を顔に落としたくないとき |
| `LightBlockMask` | 特定の番号のライトだけ受けないようにする | ライト 0 番を無視するなら `LightBlockMask : 1,0,0,0` |

> **AO(アンビエントオクルージョン)** とは「すき間や奥まった所は光が届きにくくて暗くなる」ことです。
> 服のシワの奥や、腕と体のすき間が少し暗くなるのがこれです。

## 6. テクスチャ(画像)を使った設定

数字ではなく**画像でパラメータを場所ごとに変える**こともできます。
例えば「金属の板の、さびている所だけザラザラにする」といったことができます。

### 画像の指定のしかた

```text
_T NormalMap : t/my_normal.png
_T RoughnessMap : t/my_rough.png
```

- 行の先頭に `_T` を付けて、`_T 画像の種類 : ファイルのパス` と書きます。
- パスは**その材質設定ファイルがあるフォルダから見た場所**で書きます。

### 画像の種類

| 種類 | 何を変えるか | イメージ |
|---|---|---|
| `NormalMap`(法線マップ) | 表面の**凸凹**(本当に形を変えずに、光の当たり方だけ凸凹に見せる) | 青紫っぽい画像 |
| `RoughnessMap` | 場所ごとの**ザラザラ具合** | 白黒画像(白ほどザラザラ) |
| `AlbedoMap` | **地の色**を画像で置き換える | ふつうのカラー画像 |
| `AlphaMap` | 場所ごとの**透明度** | 白黒画像(黒ほど透明) |
| `AOMap` | 場所ごとの**すき間の暗さ** | 白黒画像(黒ほど暗い) |
| `SubAlbedoMap` | 地の色に**汚れ・模様を重ねる** | カラー画像(`SubAlbedoOp` で重ね方を選ぶ) |
| `ClearcoatMap` / `ClearcoatNormalMap` / `ClearcoatRoughnessMap` | 透明な膜の強さ・凸凹・ザラザラ | 水滴、ニスのムラ |
| `DisplacementMap` | 表面の高さ | 白黒画像 |
| `RampLUT` / `RampZH` | 陰影の付き方(トゥーン・肌) | 付属の `t/*.dds` を使用 |
| `IridescenceLUT` / `IridescenceMap` | 角度で変わる色・膜の厚さ | 付属の `t/*.dds` を使用 |

### 画像の効き方を調整するパラメータ

それぞれの画像に、次の 3 つの調整用パラメータがあります(`Normal` の部分を `Roughness`、`Albedo` などに読み替えてください)。

| パラメータ | 意味 | 例 |
|---|---|---|
| `NormalLoops` | 画像を何回くり返して貼るか(タイル貼り) | 5 にすると 5×5 回くり返す |
| `NormalScale` | 画像の効き具合 | 凸凹を強くしたいなら 2 |
| `NormalUV` | どの UV(画像の貼り方)を使うか | ふつうは 0 のまま |

- `TextureLoops` は、すべての画像のくり返し回数にまとめて掛かる倍率です。
- `AutoNormal` を使うと、**法線マップ画像が無くても**、モデルの色テクスチャの明暗から自動で凸凹を作ります(髪の毛の筋などに便利)。

## 7. Sモード(Subayai-S)での見え方の違い

**Sモード**は、ハードウェアレイトレーシング機能(RTX シリーズなどに搭載)を持たない GPU 向けの動作モードです。
Sモードでは Subayai の代わりに **Subayai-S** を使います。材質設定ファイルの書き方は **Subayai とまったく同じ**です。

ただし、計算方法の違いにより、次のような見え方の違いがあります(初期バージョン時点)。

| 見た目 | Subayai(通常モード) | Subayai-S(Sモード) |
|---|---|---|
| 金属・ツルツルの物の映り込み | 周りの物(キャラクターなど)も映る | **画面に映っている物だけが映る**(画面の外にある物や、物の裏側は映らず、代わりに空が映る) |
| ガラスの向こう側 | 曲がって(屈折して)見える | 曲がらずに透けて見える |
| 影 | 半透明の物の影も淡く出る | 半透明の物の影も淡く出る(半透明の物が何枚も重なる場所では、少し濃くなることがある) |
| 遠くの影(太陽の光による影) | どこまで遠くでも出る | カメラから約 32m(MMD の長さで 400)より遠い所には出ない |

> 材質設定ファイルは Subayai-S 専用のフォルダ(`renderer/Subayai-S/m/`)にも同じものが入っています。
> Sモードで Subayai のプロジェクトを開くと、自動的に Subayai-S と、そのフォルダの同じ名前の設定ファイルに切り替わります。
>
> 床の映り込みは、8 章の WorkingFloor を使うと、画面の外にある物まで正しく映せます。

## 8. 床の映り込み: WorkingFloor (Subayai-S 専用)

### どんな機能?

ステージの**床にキャラクターや天井が鏡のように映り込む**表現です(MMD でいう「ワーキングフロア」)。
画面の外にある物や、キャラクターの裏側も正しく映ります。

### 設定の考え方: 「映す物」と「映る物」は別

| 役割 | 意味 | 例 | 設定 |
|---|---|---|---|
| **映す物(床)** | 映り込みが表示される平らな面 | 床、鏡、水面 | **材質設定ファイルで `WorkingFloor : 1` を指定** |
| **映る物** | 床に映り込む物 | キャラクター、小物、天井 | 床より上にある物は**すべて自動で映る** |

材質設定ファイルで指定するのは「**どの材質を鏡のような床にするか**」です。「どの物を映すか」を選ぶ設定ではありません。

### 使い方

1. レンダラを **Subayai-S** にする
2. Materials ウィンドウで床の材質にチェックを入れ、**load MatDesc** で `renderer/Subayai-S/m/WorkingFloor.txt` を選ぶ

付属の `WorkingFloor.txt` の中身はこうなっています。

```text
WorkingFloor : 1      # この材質を映り込みのある床にする
Roughness : 0.05      # 映り込みのくっきり具合(0:鏡のよう ～ 0.3:ぼんやり。0.5以上では映り込まない)
IOR : 1.8,0           # 映り込みの強さ(1.5:控えめ ～ 2.5:強め)
```

- 床の模様(テクスチャ)はそのまま残り、その上に映り込みが重なります。
- 床を斜めから見るほど、映り込みは自然に強くなります(2章のフレネル効果)。

### 注意

- **平らな面**にだけ使ってください。段差や曲面では正しく映りません。
- 同時に使える床は **1 枚**です。高さの違う複数の床に指定すると、画面に映っている床を平均した高さの床として扱われます。
- 床が画面にほとんど映っていないときは、映り込みは計算されません。
- 映り込みの中の物は、少し簡略化した明るさの計算で描かれます(すき間の暗さ(AO)や、肌のやわらかさ(SSS)は省略されます)。

## 9. 困ったときは

| 症状 | 考えられる原因と対処 |
|---|---|
| 全体的に白っぽい | `AlbedoEstimation : mmd` になっていないか確認(標準は `diffuse`) |
| 金属が真っ黒 | 金属は周りの物を映して見えるので、背景(skybox)が暗いと黒く見えます。背景を明るい画像にするか、`Roughness` を上げてみてください |
| 顔の影が濃すぎる | `ShadowVisibility : 0.5,0.5,0.5` などで影を弱める |
| 白目が暗い | `eye.txt` を当てる(影と AO を弱める設定) |
| 髪の先がチラチラする | `Cutout : 0.5` を試す |
| ファイルを書き換えたのに変わらない | Materials ウィンドウの **reload** を押す |
| 設定ファイルのエラーが出る | `名前 : 値` の綴り間違い、全角文字の `:`、カンマ区切りの数の過不足がないか確認 |
